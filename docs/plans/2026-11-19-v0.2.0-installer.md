# Frost 0.2.0: installer + "default file manager" prompt

Spec: user request: "make the file an installer in 0.2.0 and make it prompt the user if he wants to change his default file explorer if that's even possible on windows".

## Global Constraints
- No NuGet packages, no admin rights: per-user install only (HKCU, %LocalAppData%). Must build on Linux (`dotnet build Frost.slnx`, EnableWindowsTargeting); cannot be run here.
- One exe does both jobs: the release asset is `Frost-Setup-0.2.0.exe` (the same published Frost.exe, renamed). Setup mode = `--install` arg OR the exe's file name contains "setup" (case-insensitive). Otherwise Frost runs normally.
- Install dir: `%LocalAppData%\Programs\Frost\Frost.exe`. Version 0.2.0 in Frost.App.csproj (`<Version>0.2.0</Version>`).
- UI matches the existing Liquid Glass theme (`Themes/Glass.xaml`, DialogWindow style); keyboard accessible.
- Default-file-manager hook is opt-in, fully reversible, HKCU only (the same approach the Files app uses; Windows has no official API):
  - `HKCU\Software\Classes\Directory\shell` (Default) = `openinfrost`; `...\Directory\shell\openinfrost` (Default) = `Open in Frost`; `...\openinfrost\command` (Default) = `"<install>\Frost.exe" "%1"`
  - Same three keys under `HKCU\Software\Classes\Drive\shell`
  - Win+E / This PC: `HKCU\Software\Classes\CLSID\{52205fd8-5dfb-447d-801a-d0b52f2e83e1}\shell\opennewwindow\command` (Default) = `"<install>\Frost.exe"`, value `DelegateExecute` = "" (empty string)
  - Disable = delete exactly those keys we created (Directory\shell default value only if it is still `openinfrost`; the whole `openinfrost` subkeys; the CLSID key tree we created). Never touch HKLM.
  - Broadcast `SHChangeNotify(SHCNE_ASSOCCHANGED, 0, NULL, NULL)` after changes.

## Task 1: Installer, uninstaller, default-handler toggle
1. `Frost.Shell` gets `public static class DefaultFileManager { bool IsEnabled(); void Enable(string exePath); void Disable(); }` (registry above, Microsoft.Win32.Registry, never throws on Disable).
2. Setup window (new `SetupWindow.xaml`, glass style) shown instead of MainWindow in setup mode:
   - Title "Install Frost 0.2.0", install path shown (read-only), checkboxes: "Start menu shortcut" (on), "Desktop shortcut" (off), "Make Frost my default file manager (opens folders, drives and Win+E in Frost; you can undo this anytime)" (off by default, explicit opt-in), "Launch Frost when done" (on).
   - Buttons: Install (primary), "Run without installing" (opens MainWindow normally), Cancel.
   - Install: create dir, copy own exe (Environment.ProcessPath) to install dir as Frost.exe (overwrite = upgrade; if target is running, show a friendly error asking to close Frost), create .lnk shortcuts (IShellLinkW/IPersistFile via ComImport in Frost.Shell, or WScript.Shell via `Type.GetTypeFromProgID` dynamic: pick the smaller working one), write uninstall entry `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\Frost` (DisplayName "Frost", DisplayVersion "0.2.0", Publisher "GhostfazeRel", DisplayIcon = exe, InstallLocation, UninstallString = `"<exe>" --uninstall`, NoModify=1, NoRepair=1, EstimatedSize KB), optionally enable default handler, then launch installed Frost and exit.
   - Errors shown in the glass dialog, never crash.
3. `--uninstall`: confirm dialog ("Uninstall Frost? Your settings in %AppData%\Frost are kept."), then: Disable default handler, delete shortcuts + Uninstall key, then self-delete the install folder via `cmd.exe /c timeout /t 2 /nobreak >nul & rmdir /s /q "<dir>"` (hidden window) and exit.
4. In the running app (not setup mode): the "…" menu gets a toggle item "Make Frost the default file manager" / "Restore Explorer as default" (state from IsEnabled). Enabling uses the current exe path; show a notice after toggling.
5. First-run prompt: on first normal launch of an INSTALLED Frost (ProcessPath is in the install dir) where the default handler is not enabled and the setting `AskedDefault` is false, show a glass dialog "Make Frost your default file manager?" (Yes / Not now), then set `AskedDefault = true` (new AppSettings bool). Skip if the user already chose in setup.
6. Startup argument robustness: if args[0] is not an existing directory (e.g. `::{CLSID}` shell paths like Recycle Bin or Control Panel passed by Windows while Frost is default), launch `explorer.exe` with that argument and exit, so special folders still work. No args → normal start.
7.
